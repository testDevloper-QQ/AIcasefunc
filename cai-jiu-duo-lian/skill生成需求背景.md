# 我的菜谱 Skill — 需求背景

## 1. 项目概述

### 1.1 项目名称

菜谱网页标题：**菜就多练**

### 1.2 功能介绍

当用户不知道吃什么菜、小吃、甜点、饮品、凉菜、汤、面等时，可根据本地收集的各地菜谱及饮食类参考资料作为主要来源进行推荐；若可访问小红书等平台，可补充有权威性、评论区经大众验证、不踩雷的高赞收藏视频或图文笔记，向用户推荐相应菜品。

---

## 2. Skill 生成要求

### 2.1 基本要求

- 用户安装 Skill 后可**开箱即用**
- 生成 Skill 相关文件时，须同步提供**用户使用指南**

1. 生成 Skill 之前，先根据本需求进行**头脑风暴**
2. 待方案可行性确认后，再进入实现阶段

## 4. 用户场景拓展

- 调理身体、注重营养（轻食、抗炎、备孕、慢性病等）
- 快餐满足、快乐至上
- 时令食材、鲜味为王
- 地方菜、我的地盘我做主
- 便当、上班族的最爱
- 甜点、小吃、饮品、小份量的快乐

## 5. 注意事项


| 序号  | 要求                             |
| --- | ------------------------------ |
| 1   | 不要泛大众，要有独特创意                   |
| 2   | 推荐菜品时，不要捏造不存在的菜品               |
| 3   | 不要输出与用户推荐相反的内容                 |
| 4   | 不要一人食推荐 2 人食量，不要 2 人食量推荐 1 人食量 |
| 5   | 优先从本地模板出菜，其次从小红书中找推荐菜          |
| 6   | 不要输出与用户不相关的内容                  |

## 7. Skill 结构



### 7.1 用户画像

- 职场上班族、一人食等不想在做饭上花费决策精力的人群
- 注重健康、时令、希望饮食多样化的人群



### 7.2 用户输入


| 序号  | 输入方式                                           | 是否必选   |
| --- | ---------------------------------------------- | ------ |
| 1   | 打字输入食材                                         | 可选     |
| 2   | 上传食材照片                                         | 可选（v2） |
| 3   | 从现有食材分类、口味、菜品分类示例中点选按钮提交（**至少选择一个食材**才能提交）     | 食材必选   |
| 4   | 一人食 / 二人家庭 / 多人家庭                              | 可选     |
| 5   | 网页「今天想吃什么？」饮食偏好（便当 / 轻食 / 时令 / 地方味 / 调理 / 快乐餐） | **可选** |




### 7.3 主功能

支持按口味（清淡、麻辣等）、菜品类型（小吃、正餐、甜点、饮品、汤面等）、烹饪方式（煎炒烹炸）、食材等维度，推断用户偏好并推荐相应菜品。

### 7.4 输出内容

推荐菜谱，包含：

- 图片
- 做法步骤
- 食材清单
- 预计花费
- 烹饪时间
- 烹饪方式



### 7.5 功能拓展

暂无

### 7.6 功能范围

- **核心功能**：推荐菜谱
- **原则**：尽量简化，不要增加其他功能

---



## 8. 限制条件

1. 只提供日常做菜的参考，不能提供非常专业的营养师、高级厨师水平的内容
2. 当前只提供简单便捷的能力，不支持过多存储、下载、分享等功能

---



## 9. 风格规范


| 维度   | 要求                                            |
| ---- | --------------------------------------------- |
| 整体风格 | 清新、治愈、极简、自然；适当趣味，避免过于寡淡                       |
| 配色   | 暖黄色（#FFF8E7 背景，#E8A838 强调）                    |
| 点缀元素 | **食材线稿 + 淡水彩填充**；参考中国饮食元素（饭碗筷、炒锅、白菜、鸡腿卤蛋、豆腐等） |
| 网页标题 | 手写趣味字体（站酷快乐体），俏皮可爱                            |
| 排版   | 卡片式分区，注重留白，不破坏整体风格                            |

### 10.2 网页表单字段


| 字段      | 文案                                         | 必选         |
| ------- | ------------------------------------------ | ---------- |
| 饮食偏好    | **今天想吃什么？**（便当 / 轻食 / 时令 / 地方味 / 调理 / 快乐餐） | 否，可点选可取消   |
| 食材      | 冰箱里有什么？（蔬菜 / 肉蛋 / 主食 / 豆奶果）                | **至少 1 个** |
| 口味 / 类型 | 可选                                         | 否          |
| 份量      | 一人食 / 二人 / 多人                              | 否          |
| 补充说明    | 可选                                         | 否          |




### 10.3 网页视觉规范

- 标题「菜就多练」：手写体（ZCOOL KuaiLe），带淡色装饰
- 图标：**线稿 + 淡水彩半透明填色**，禁用 emoji 图标
- 食材分组图标：参考中国饮食元素（炒锅蔬菜、鸡腿卤蛋、饭碗筷子、豆腐等）
- 场景卡片：6 类饮食偏好，每项含线稿图标 + 名称 + 简述
- 交互：静态 HTML + 普通 JS（兼容 `file://` 打开）；提交后生成结构化 Prompt



### 10.4 网页 v2（在线推荐）

- 通过 `python scripts/web_server.py` 启动本地服务（默认 `0.0.0.0:8765`）
- 提交表单后 **直接调用 Skill 索引** 返回菜谱到当前页面，无需粘贴 Cursor
- 支持 PWA 添加到手机桌面（需通过 http 访问，手机与电脑同一 WiFi）
- Skill 来源可配置：
  - `local`：本地路径（默认 `web/config.json` → `localSkillPath: ".."`)
  - `git`：远程 Git 仓库（填写 `gitRepoUrl`、`gitBranch`、`gitSkillSubPath`）
