|---------|--------|-----------|-------------|----------|

## 请求类型路由

- 多个食材 → ingredient 模式 → 按食材 tag 过滤索引
- 指定菜名/技法 → specific 模式 → 按 name/tags 精确匹配
- 仅场景/心情 → craving 模式 → 按 scene 过滤索引

## 反向过滤（禁止推荐）

| 场景 | 禁止 |
|------|------|
| light-meal | 重油炸、高糖甜点 |
| health | 高汞鱼、未熟蛋、酒精（孕期） |
| seasonal | 反季强行推荐（无依据时） |
