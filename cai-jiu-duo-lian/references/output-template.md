# 输出模板

## 标准格式

```
🍳 推荐：[菜名]
📖 出处：《[书名]》· [场景标签]
⏱ [烹饪时间] · 💰 [预计花费] · 🔥 [烹饪方式]

[图片：优先 line_art 路径；联网可选公开图 URL]

🥬 食材清单（[N] 人份）
1. ...

👩‍🍳 做法步骤
1. [步骤配图] 步骤文字
2. ...

💡 关键提示
- ...

🔄 替代方案
- ...
```

## 输出质量检查（必做）

对标 [`dietary-guidelines-cn.md`](dietary-guidelines-cn.md)（《中国居民膳食指南（2022）》单餐估算）：

| 检查项 | 标准 |
|--------|------|
| 烹饪时间 | ≤ 60 分钟（含备料+烹饪）；超时菜品不推荐 |
| 鱼禽肉蛋（主荤） | 50–100 克/人·餐 |
| 蔬菜 | 100–170 克/人·餐 |
| 谷薯 | 70–100 克/人·餐 |
| 盐 | ≤ 2 克/人·餐（日摄入 < 5 克） |
| 烹调油 | ≤ 10 克/人·餐 |
| 添加糖（咸味菜） | ≤ 15 克/人·餐 |
| 批量配方 | 须按膳食指南换算并标注 |
| 步骤配图 | 每步配线稿图标或公开图 |

## 字段说明

| 字段 | 要求 |
|------|------|
| 菜名 | 须能在本地资料中找到依据 |
| 图片 | 优先 `assets/line-art/` 线稿；联网可选公开图 |
| 食材清单 | 按用户份量缩放 |
| 预计花费 | 粗估，标注「约」 |
| 烹饪时间 | 含备料 + 烹饪 |
| 烹饪方式 | 煎/炒/烤/凉拌等 |
