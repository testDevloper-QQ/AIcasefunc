# 输出模板

## 标准格式

```
🍳 推荐：[菜名]
📖 出处：《[书名]》· [场景标签]
⏱ [烹饪时间] · 💰 [预计花费] · 🔥 [烹饪方式]

[图片：优先 line_art 路径；联网可选公开图 URL]

🥬 食材清单（[N] 人份）
1. ...

👩‍🍳 做法步骤
1. ...

💡 关键提示
- ...

🔄 替代方案
- ...
```

## 字段说明

| 字段 | 要求 |
|------|------|
| 菜名 | 须能在本地资料中找到依据 |
| 图片 | 优先 `assets/line-art/` 线稿；联网可选公开图 |
| 食材清单 | 按用户份量缩放 |
| 预计花费 | 粗估，标注「约」 |
| 烹饪时间 | 含备料 + 烹饪 |
| 烹饪方式 | 煎/炒/烤/凉拌等 |
